## ✨ Overview

This is the source code for my personal portfolio website — a single-page application built to showcase my background, skills, and projects as a Computer Science & Engineering student. It's fully responsive, supports light/dark mode, and is built with a modern React + TypeScript + Tailwind CSS stack.

## 🚀 Live Site

👉 **[https://adnanahamedarif.github.io](https://adnanahamedarif.github.io)**

## 📸 Sections

| Section | Description |
|---|---|
| **Hero** | Introduction, role, and quick links to GitHub/CV |
| **About** | Education background, short bio, and downloadable CV |
| **Journey** | Timeline of academic & personal milestones |
| **Skills** | Tech stack with category breakdown (Languages, Frontend, Backend, Tools) |
| **Work** | Featured projects with live links, GitHub repos, and tech tags |
| **Contact** | Contact form for reaching out directly |

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React
- **Animation:** Motion (Framer Motion)
- **AI Integration:** Google Gemini API (`@google/genai`)
- **Deployment:** GitHub Pages



## 💻 Getting Started

**Prerequisites:** [Node.js](https://nodejs.org/) (v18+)

```bash
# 1. Clone the repository
git clone https://github.com/adnanahamedarif/adnanahamedarif.github.io.git
cd adnanahamedarif.github.io

# 2. Install dependencies
npm install

# 3. (Optional) Set your Gemini API key
cp .env.example .env.local
# then edit .env.local and add your GEMINI_API_KEY

# 4. Run the dev server
npm run dev
```
